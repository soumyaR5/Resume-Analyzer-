# 🚀 AI Resume Analyzer

AI Resume Analyzer is an intelligent system that evaluates resumes against job descriptions using **Natural Language Processing (NLP)** and **Large Language Models (LLMs)**. It generates an **ATS score**, identifies **missing skills**, and provides **actionable feedback** to improve candidate resumes.

---

## 📌 Features

* 🔍 Resume vs Job Description Matching
* 📊 ATS Score Calculation
* 🧠 Skill Extraction using NLP
* ❗ Missing Skills Identification
* 💡 AI-powered Suggestions for Improvement
* ⚡ Fast and interactive analysis
